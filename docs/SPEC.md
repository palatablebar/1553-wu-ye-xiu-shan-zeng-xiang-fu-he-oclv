# 物业修缮增项复核数据与算法

导入自备批次或复核估计时阅读。先核对下面的字段和时间窗。查看隔离行原因，再核对估计和派发结果。

## 单据

| 字段 | 用途 | 单位 | 有效区间 |
|---|---|---|---|
| `extra_pct` | 增项金额占比 | % | 2–90 |
| `revisions` | 工程量签单修订 | 次 | 0–14 |
| `photos` | 抽验影像证据 | 张 | 0–42 |
| `quote_age` | 报价生效天数 | 天 | 4–83 |
| `works` | 作业项数 | 项 | 1–38 |
| `vendor_lag` | 施工方回应 | h | 2–70 |

`key` 是单号，`cohort` 是作业区，文本先做 NFKC 归一化。`day` 为测量工日，`received` 为到站工日，`revision` 为正整数版次。同版记录出现多个不同测量结果时隔离该单全部版次。缺测可空置，但每条单至少包含四项观测。

`outcome` 与 `result_day` 成对填写。标签 0 为已核实正常，1 为需要复核的实绩。 `observed` 省略时为 `true`，只在留架右截尾场景允许 `false`。

### 原始行业单据

允许使用 `form` 对象代替平铺量测。保留单号、版次、工日和标签等顶层字段。表中的换算为 `(单据值 − 原点偏移) / 倍率`。每行内部校验完成后，与平铺数据使用同一分窗、建模和派单过程。

| 单据组 | 原始字段 | 用途 | 倍率 | 原点偏移 |
|---|---|---|---:|---:|
| 增项结算 | `scope_diff_basis_points` | 增项万分比 | 100 | 0 |
| 增项结算 | `rewrites` | 工程量修订次数 | 1 | 0 |
| 工程量签证 | `inspection_photos` | 见证图片数量 | 1 | 0 |
| 工程量签证 | `quote_age_hours` | 认可报价小时 | 24 | 0 |
| 复核证据 | `changed_operations` | 现场作业项 | 1 | 0 |
| 复核证据 | `vendor_respond_minutes` | 施工方回应分钟 | 60 | 0 |

示例见 `sample_data/variation_forms_form.json`。混合使用两种量测表示，或单据内读数互相矛盾时，保留隔离原因。

## 时序与训练

拟合 `[2,40)`、校准 `[42,62)`、回放 `[65,84)`、当班从 `88` 日起。前三个窗口的入站和结果都须早于窗口终点。到站日晚于截止日的单据在入站隔离。拟合期冻结补值中位数、均值、尺度及训练包络。

| 特征 | 语义 | 公式 |
|---|---|---|
| `price_pressure` | 增项占比 | `extra_pct` |
| `quantity_change` | 单位作业的改量频率 | `revisions/(works+2)` |
| `evidence_gap` | 每份证据对应作业 | `works/(photos+1)` |
| `late_offer` | 报价与交割延迟 | `quote_age/7+vendor_lag/24` |
| `unconfirmed_scope` | 未复核工作量 | `extra_pct*works/(14+photos)` |

### PAV 保序增项评分卡

对各关键因素按训练数据分箱，合并破坏单调性的相邻箱。局部箱内风险向整体先验平滑，再按领域权重组合。

本工作台的独立样本校准方式为增项评分向实绩先验收缩。风险校准无法确认正负样本时转人工判读。连续估计使用独立校准残差计算双侧区间，误差尺度随作业条件变化。分布监测对训练和当班量测比较分位位移。未知作业区、两项缺测或两项明显超训练包络的单据需要人工判读。

## 提交造价复核

| 优先级 | 原因码 | 条件 | 处置依据 |
|---:|---|---|---|
| 1 | `NO_WITNESS` | `photos <= 2 and extra_pct > 55` | 增项缺见证资料 |
| 2 | `QUOTE_EXPIRED` | `quote_age > 66 and extra_pct > 32` | 重索有效报价 |
| 3 | `CHANGE_VOLUME` | `revisions >= 9 and works >= 13` | 申请第三方复量 |

第一条为暂停规则。其余命中与模型阈值 `0.5` 共同决定是否列入候选。单据所需工位数按 `1 + int(works>18) + int(extra_pct>57)` 计算。均衡策略对分区限额，集中复核策略允许把额度集中投入高风险区。未分派原因在导出的处置记录中保留。签发前核对每张当班单和工位余额。

### 增项附件核对单

按每个作业项至少两张照片检查附件，按报价有效期和施工方回复时点排序。缺见证、过期报价和修订过多分别生成对应的补件或复量安排。 在派发环节展开现场安排，或从关联单据回查实际读数。

### 复量预算合查单

同一作业面（`cohort`）的当班签单可组合作业面合查，合查凭证须让覆盖签单与实占工位双向核对一致。

| 规则 | 口径 |
|---|---|
| 凭证核对 | 合查已覆盖签单与主派单已分派签单完全一致；合查实占 + 共用省位 = 主派单实占，余额随之变动 |
| 高风险优先 | 工位只够合查时，按作业面校准后覆盖风险降序排定优先序，排序键全部确定化 |
| 缺见证暂停 | 命中 `NO_WITNESS` 的签单为硬暂停，不进入合查组、不占工位，暂停原因保留到台账 |
| 共用测项省位 | 只有登记同场共用证据、且被组内至少两张签单实际覆盖的测项才合并复量；每个证实共用测项省一个工位，合查组至少保留一个工位 |
| 单测照计 | 未证实共用、或仅被单张签单覆盖的测项按单测照常计占用，缺测字段不计入覆盖 |
| 覆盖风险 | 按各签单实际覆盖测项数加权预测，再用独立校准窗实绩向先验收缩；校准样本不足或正负单一时保留原风险并标记人工判读 |
| 防样本泄漏 | 同一作业面的成熟实绩不得同时落入训练窗 `[2,40)` 与校准窗 `[42,62)`；同单号跨窗或同作业面量测指纹相同即拒绝整批复算 |
| 重跑一致 | 同一批输入无论次序如何，覆盖签单、共用/单测测项、工位占用与风险序完全一致；候补组按单测口径登记，省位仅在实际合查分派时生效 |

共用证据登记格式为 `{测项编号: (单号, ...)}`，测项编号取 `extra_pct`、`revisions`、`photos`、`quote_age`、`works`、`vendor_lag`。证据引用未登记签单、超出签单实际覆盖范围或只覆盖单张签单时直接拒绝。合查结果在 `joint_review` 字段输出作业面明细、台账与风险优先序，不改变既有派单凭证哈希。
